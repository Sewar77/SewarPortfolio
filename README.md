# 🧠 Architecture

The portfolio uses the **Next.js App Router** with a structure designed to keep content, components, and application logic organized.

```text
src/
│
├── app/
│   ├── work/
│   │   └── [slug]/
│   ├── globals.css
│   ├── layout.tsx
│   ├── page.tsx
│   ├── manifest.ts
│   ├── robots.ts
│   └── sitemap.ts
│
├── components/
│   ├── navigation
│   ├── project previews
│   ├── animated reveals
│   ├── page sections
│   └── architecture components
│
└── data/
    ├── portfolio.ts
    └── case-studies.ts

public/
│
├── projects/
│   ├── training-center/
│   └── subh/
│
└── cv.pdf
```

Most of the application uses **Server Components**.

Client Components are used only when browser interaction is required, including:

* Navigation state
* Theme behavior
* Interactive terminal
* Scroll animations
* Interactive UI elements

# 🚀 Run Locally

### Requirements

* Node.js 20.9+
* npm

Clone the repository:

```bash
git clone https://github.com/Sewar77/SewarPortfolio.git
```

Enter the project:

```bash
cd SewarPortfolio
```

Install dependencies:

```bash
npm install
```

Start development:

```bash
npm run dev
```

Open:

```text
http://localhost:3000
```

---

# ✅ Production Checks

Before deploying:

```bash
npm run typecheck
npm run lint
npm run build
```

Format the project:

```bash
npm run format
```

# ⚙️ Environment Variables

Create:

```text
.env.local
```

Add:

```env
NEXT_PUBLIC_SITE_URL=https://sewarportfolio.onrender.com
```

This value is used for:

* Canonical URLs
* Metadata
* Sitemap
* Structured data
* Social previews

# ☁️ Deployment

The portfolio is currently deployed on **Render**.

### Production URL

👉 **https://sewarportfolio.onrender.com/**

When deploying to another provider or custom domain, update:

```env
NEXT_PUBLIC_SITE_URL=https://your-new-domain.com
```

Then rebuild and redeploy the project.

The website was designed to remain lightweight and responsive.

* Server Components by default
* Limited use of Client Components
* Reusable components
* Optimized rendering
* CSS-based project previews
* Minimal unnecessary JavaScript
* Responsive assets
* Next.js optimizations
